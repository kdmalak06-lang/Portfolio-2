# Md Abdul Malak - Google Ads Portfolio Website

Static site (no build step). Files: `index.html`, `assets/`, the PDF portfolio, `netlify.toml`.

## Deploy
1. Push this folder to a GitHub repository.
2. In Netlify: Add new site > Import from Git > pick the repo.
3. Build command: leave empty. Publish directory: `.` (already set in `netlify.toml`). Deploy.
